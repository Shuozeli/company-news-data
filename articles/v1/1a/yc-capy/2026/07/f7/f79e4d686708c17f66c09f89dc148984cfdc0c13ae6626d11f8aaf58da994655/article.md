# Introducing SDK 2.0

## We are on a mission to empower AI agents with robust, secure, and scalable virtual desktop infrastructure.


Today marks our first major update. We are excited to introduce SDK 2.0 for Python and TypeScript, an official REST API endpoint, four new protocol APIs (Browser, Code, File, and Env), subscription pricing for power users, and more.


## TypeScript + REST API


Available today, spin up Scrapybara instances directly through the[TypeScript SDK](https://docs.scrapybara.com/sdk-reference/typescript) and[REST API](https://docs.scrapybara.com/api-reference) .


## Browser Control


Scrapybara now supports programmatic browser control through Playwright. Empower your agents with direct HTML DOM input and manipulation (in addition to visual computer use controls) to better support web automation, data collection, and interaction testing. Learn more[here](https://docs.scrapybara.com/browser) .


## Authentication Management


Authenticate automatically on popular websites like LinkedIn, X, GitHub, Amazon, etc. Our secure session management allows AI agents to maintain authenticated states across sessions, eliminating the need for frequent re-authentication while maintaining security standards.


## Code Execution


Developers can now execute code directly within Scrapybara instances, and allow agents to launch and control entire Jupyter Notebooks (Python, Javascript, R). Learn more[here](https://docs.scrapybara.com/code) .


## Filesystem Control


We have introduced comprehensive filesystem management capabilities, giving AI agents full control over file operations. Learn more[here](https://docs.scrapybara.com/file) .


## Environment Variables


Our new environment variable interface allows for dynamic configuration of instance settings, making it easier to manage different deployment environments and application configurations. Learn more[here](https://docs.scrapybara.com/env) .

For organizations with specific security requirements or compliance needs, we now offer self-hosted deployment options. Get complete control over your infrastructure while maintaining all the benefits of our platform. Interested? Book a demo[here](https://cal.com/team/scrapybara/enterprise) .
