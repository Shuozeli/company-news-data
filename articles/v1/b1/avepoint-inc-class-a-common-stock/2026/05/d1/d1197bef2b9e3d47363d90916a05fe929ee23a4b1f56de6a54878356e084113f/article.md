# Microsoft Project Online Retirement: What AvePoint Cloud Backup Customers Need to Know

Microsoft has announced the retirement of Project Online, also known as Project Web App or PWA, on September 30, 2026. For organizations still relying on Project Online, this change affects how long project data remains accessible and what steps are needed to retain it.


For customers using AvePoint Cloud Backup for Microsoft 365 to protect Project Online data, this Microsoft retirement has significant implications. Because AvePoint’s Cloud Backup relies on Microsoft-provided Project Online APIs, backup and restore operations will end once Microsoft retires the service.


## What's Changing with Project Online Backup and Restore


After September 30, AvePoint will:


- Stop running new Project Online backup jobs.


- Disable the restoration of Project Online data.


## What Does This Mean for Your Existing Project Online Backup Data?


Your existing Project Online backup data will remain stored according to your current subscription, storage configuration, and retention settings. However, once Microsoft retires Project Online, restore operations will no longer be possible, making it important to export any data you may need for future access, compliance, or archival purposes.


## What Should Customers Do Now?


Customers who currently protect Project Online with AvePoint Cloud Backup for Microsoft 365 should begin planning now to export any Project Online backup data they may need to retain.


AvePoint Cloud Backup supports exporting backup data from a Project Online site, including:


- Libraries.


- Lists.


- Folders.


- Items.


- Documents.


To export Project Online backup data, customers can use AvePoint Cloud Backup's export capability.


To help you retain access to important project data, AvePoint Cloud Backup offers flexible export options for Project Online. At a high level, you can export content directly from the Cloud Backup interface, selecting the data and backup point that best fit your needs.


[Detailed instructions are available](https://learn.avepoint.com/m365/export-and-download-your-data/export-project-online-data.html) in the product and in our documentation, and


[a standalone data export service](https://learn.avepoint.com/m365/cloud-backup-for-microsoft-365-standalone-tool.html) is also available for broader export needs.


At a high level, customers can export Project Online data by navigating to **Restore > AvePoint Cloud Backup** , selecting the **Project Online** tile, choosing the items they want to export, and clicking **Export** . Customers can locate data using either search-based selection or calendar-based backup job selection, depending on whether they want to search for specific content or browse data from a particular backup point.


## Why Exporting Your Project Online Data Matters


After Project Online is retired and the Microsoft APIs are no longer available, AvePoint will be unable to perform Project Online restore operations. Exporting your Project Online backup data allows you to keep a copy of important project information outside of the retired service.


Exporting your Project Online backup data helps ensure that beyond the service’s retirement date, you retain access to:


- Critical project information for long-term archival.


- Compliance and audit requirements.


- Historical reference.


- Internal reporting.


Export capabilities will remain available **for as long as your subscription is active. We will retain the data for the retention period you selected in the product.**


## Recommended Timeline for Project Online Customers


We recommend that customers review their Project Online backup data and **complete any necessary exports** **before October 1, 2026** .


While Microsoft’s retirement date is September 30, 2026, **AvePoint’s Project Online backup and restore changes will take effect on** **October 1, 2026** . Beginning that day, AvePoint will stop running new Project Online backup jobs and will disable Project Online restore capability because the Microsoft APIs required for these operations will no longer be available.


## Key Takeaways


- Microsoft will retire Project Online on September 30, 2026.
- Starting October 1, 2026, AvePoint will no longer run Project Online backup jobs or support restore operations.
- Customers should export any Project Online backup data they need to retain before that date.
