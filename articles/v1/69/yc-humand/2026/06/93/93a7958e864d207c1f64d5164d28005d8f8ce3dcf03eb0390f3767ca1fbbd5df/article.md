# New Time Off settings: 7-day block request and Monday starts

**Time Off** module now features new validation rules to ensure vacation requests align with 7-day blocks and start on specific dates. This simplifies internal planning and ensures compliance with company policies.


### **Order and Predictability in Leave Management**


Previously, validating the duration and start date of a vacation request required a manual review of each submission. With these new options, the system automatically ensures compliance. This tool not only reduces HR’s operational workload but also provides clarity to employees when planning their days off, guaranteeing that every request is valid right from the start.


### **What’s included in the new validations?**


- **7-day increments:** The system validates that requests are made in full-week blocks (7, 14, 21 days, etc.).
- **Monday start dates:** Restricts vacation start dates to coincide with the first day of the workweek.
- **Holiday management:** If Monday is a public holiday, the tool automatically enables the next business day as a valid start date.
- **Remaining balance exception:** If an employee has a total balance of fewer than 7 days, they can request the exact remainder.
- **Independent rules:** Administrators can enable or disable each validation separately within each time-off policy.


### **Use cases: The new rules in action**


- *“The policy requires staff to take vacation in full weeks, but an employee attempts to request 10 days.”* **→** The system prompts them to adjust their request to either 7 or 14 days, ensuring the weekly block policy is respected without manual HR intervention.
- *“The Monday a vacation is set to start is a public holiday.”* **→** The platform detects the holiday and allows the request to start on Tuesday instead.
- *“A team member only has 5 vacation days left and wants to use them.”* **→** The system recognizes this is their final remaining balance and allows the request, even though it doesn’t meet the 7-day minimum.


This functionality is now available to bring greater order and predictability to leave administration, ensuring a transparent request process that aligns with current regulations for everyone in the organization.
