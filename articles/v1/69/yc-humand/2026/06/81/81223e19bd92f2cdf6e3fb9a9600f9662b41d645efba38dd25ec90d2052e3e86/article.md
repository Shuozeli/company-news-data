# User Profiles: A unified and visual experience for the entire team

Every employee’s profile in the organization now features a redesigned space, making it easier to access key information. This update introduces a clearer, more professional structure to showcase each community member’s role and professional journey.


### **Why is it important?**


With this redesign, the user profile becomes a dynamic hub that unifies how data is viewed and managed. By reducing visual friction and ensuring information is consistent across all channels, it improves accessibility and enables a more comprehensive, modern approach to talent management.


### **What’s new?**


- **Balanced visual hierarchy:** A sleek header featuring a cover photo, profile picture, and prominently highlighted core details.
- **Smart data cards:** The information section now groups personal data and segmentations into separate cards for maximum clarity.
- **Tab-based organization:** Structured navigation with dedicated tabs for *About* , *Feed* , *Groups* , and *Recognition* .
- **Empty-field filtering:** Only fields with active data are displayed, eliminating unnecessary visual clutter on the profile.
- **Full feature parity:** The exact same data hierarchy and user experience are maintained seamlessly across both the web version and the mobile app.


### **Get started today**


Explore the new profile design and strengthen your organization’s culture with a clear, professional digital identity. This functionality is already available to all users, delivering a cohesive and engaging experience with every interaction.
