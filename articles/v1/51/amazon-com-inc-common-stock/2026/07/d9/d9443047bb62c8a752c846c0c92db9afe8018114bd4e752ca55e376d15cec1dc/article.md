# Anthropic's Claude Fable 5 model back on Amazon Bedrock

---


## Key takeaways


- Claude Fable 5 is back on Amazon Bedrock.


- The model handles complex coding and knowledge tasks without intervention.


- Access it via Amazon Bedrock or Claude Platform on AWS.


---


Anthropic’s


[Claude Fable 5 AI model is available again on AWS](https://aws.amazon.com/blogs/machine-learning/safely-releasing-frontier-models-to-customers/) . Claude Fable 5 represents a step-change in AI model capabilities.


[Claude Fable 5 handles complex tasks](https://www.aboutamazon.com/news/aws/claude-fable-5-anthropic-available-amazon-bedrock) that previous models could not sustain, executing coding and knowledge work tasks without intervention. It also has advanced vision and proactive self-verification capabilities.


## How to get started with Claude Fable 5 on AWS


[Amazon Bedrock](https://aws.amazon.com/bedrock) : Build within your existing AWS environment and scale inference workloads. Access the model programmatically using the Anthropic Messages API, or use it in the Bedrock console Playground.


[Claude Platform on AWS](https://aws.amazon.com/claude-platform/) : Access through Anthropic's native platform experience.
