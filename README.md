# Company News Archive

Version-controlled company news records generated by [company-feed-server](https://github.com/Shuozeli/company-feed-server).

Current snapshot: **114751 records** across **6535 companies**.  
Generation: `8001108edc39209bd152423f49148004b7dc20049f4fcfb42f68a747561c880e`

Start with [`HEAD.json`](HEAD.json), then follow its root manifest to bounded JSONL shards. Browse readable articles under [`articles/v1/`](articles/v1/) and the machine contract under [`schemas/v1/`](schemas/v1/).

- [`ARCHITECTURE.md`](ARCHITECTURE.md) explains identity, trees, shards, and compatibility.
- [`openapi/openapi.json`](openapi/openapi.json) defines the OpenAPI 3.1 read contract.
- [`CONTENT_RIGHTS.md`](CONTENT_RIGHTS.md) explains provenance and third-party rights.
- `python3 scripts/validate_archive.py` verifies hashes and cross-references.
